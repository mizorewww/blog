# 白嫖指南：把 Grok Bot 的云电脑，变成你的 7×24 私人服务器

每个 Grok Bot 都自带一台 7×24 小时不关机的云电脑。只要 3 条命令 + 1 句话，就能把这台电脑「据为己有」——SSH 随便连、VNC 图形桌面随便用，相当于白捡一台永不离线的私人服务器。

全程 5 分钟，不需要任何运维基础。

---

## 为什么 Grok Bot 能当服务器？

Grok Bot 是 SpaceXAI（原 xAI，被 SpaceX 收购后更名）于 **2026 年 8 月 11 日**发布的 early beta 产品，与 Cursor 联合打造，官方定位是 **"AI teammates that do real work"**（能真正干活的 AI 队友）。

它和你认识的普通 Grok 完全不是一个物种：

|       | 普通 Grok     | Grok Bot                  |
| ----- | ----------- | ------------------------- |
| 本质    | 对话式 AI      | 多智能体（Multi-Agent）云端产品     |
| 干活方式  | 你问它答，动手的还是你 | 你派任务，它自己登录工具从头做到尾         |
| 硬件    | 没有          | **每个 Bot 独占一台 7×24 云端电脑** |
| 你关机之后 | 对话结束        | 它继续干活，需要审批时才来找你           |

重点就在第三行：**每个 Bot 都配一台永不离线的云电脑**——能装软件、能跑服务，还能让 Bot 自己动手配置。

这台电脑平时只是 Bot 的「工位」，但只要稍作设置，它就是一台现成的私人服务器：24 小时在线、不占你家电费、还自带一个 AI 运维。

> 目前 Grok Bot 面向 SuperGrok Heavy / Cursor Ultra / Cursor Teams Premium 订阅用户开放，客户端首发 macOS 与 iOS（Windows / Linux 可经 Cursor 使用），本文基于 macOS 讲解。

## 准备工作

- 一台 Mac
- 已安装并登录 Grok Bot（官网下载：https://x.ai/bot ）

![[99_Resources/Assets/7f61394b268c5dbbbe4ab19bca8c9bf3_MD5.png]]

## 第一步：生成 SSH 密钥（30 秒）

打开终端，输入：

```bash
ssh-keygen -t ed25519
```

然后一路回车（连按 3 次），密钥就生成好了。

## 第二步：把公钥复制到剪贴板

```bash
pbcopy < ~/.ssh/id_ed25519.pub
```

就这一条，公钥已经在你的剪贴板里了。

> 小科普：`.pub` 结尾的是**公钥**，可以随便发；没有后缀的 `id_ed25519` 是**私钥**，打死都别发出去——谁拿到私钥，谁就能进你的服务器。

## 第三步：说一句话，让 Grok 自己装好一切

回到 Grok Bot 界面，`Cmd + V` 粘贴公钥，然后对它说：

> 这是我的 SSH 公钥：（粘贴的内容）
>
> 帮我配置并运行 sshd 和 cloudflared，把本机的 SSH 和 VNC 端口通过 Cloudflare Tunnel 反代出来，并告诉我怎么连接。VNC 请帮我生成一个强密码。

然后你可以去倒杯咖啡了。Grok 会在自己的云电脑上装好 sshd、配好 Cloudflare Tunnel，跑完直接甩给你两条连接信息：一条 SSH，一条 VNC。

**自己的服务器自己装，这很 Grok。**

## 怎么连？

### SSH：命令行随便玩

Grok 会给你一条类似这样的命令：

```bash
ssh -i ~/.ssh/id_ed25519 -o ProxyCommand="cloudflared access ssh --hostname example.com" box@127.0.0.1
```

直接粘贴到终端，回车，你就进去了。（具体命令以 Grok 实际给你的为准）

### VNC：图形桌面随便用

Grok 会给你一条类似这样的命令：

```bash
cloudflared access tcp --hostname example.com --url 127.0.0.1:5902
```

1. 在终端运行它，**保持这个窗口开着**；
2. 打开 macOS 自带的「屏幕共享」（Screen Sharing）；

![[99_Resources/Assets/9d96ad100a6d21dcba4466043d76be65_MD5.png]]

3. 地址填 `127.0.0.1:5902`（以 Grok 给你的为准），输入它生成的 VNC 密码。

![[99_Resources/Assets/3fa7a55c53ae20b601278a090220dd37_MD5.png]]

熟悉的桌面出现在眼前——这台 7×24 在线的云电脑，现在是你的了。

## 拿到之后能干嘛？

- **挂机跑任务**：爬虫、脚本、定时任务，你本地关机它照跑
- **7×24 下载机**：挂下载、挂同步，不烧自己电脑的电
- **远程桌面**：出门在外，随时连回来应急办公
- **专属跳板机**：一台永远在线的中转节点
- **最骚的玩法**：让 Grok Bot 自己维护这台服务器——它是 AI，这是它的电脑，出了问题让它自己修

## 注意事项

1. **私钥不外发**：全程只用公钥，任何人（包括 Grok）找你要私钥都别给。
2. **VNC 用强密码**：让 Grok 生成足够复杂的密码，别用 123456。
3. **别放重要数据**：这是 beta 产品的云环境，随时可能重置或回收，重要文件务必自行备份。
4. **合规风险自负**：把 Bot 的云电脑当私人服务器属于「邪修玩法」，可能触碰服务条款，请自行评估账号风险。
